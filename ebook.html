Real-World Capstone Infrastructure: Pushing Research into Production

How Bangsaen AI Students Build, Attack, and Defend the Next-Gen Agent Economy

At Bangsaen AI, we reject textbook simulations. Our students engineer production-grade solutions that address the modern tech stack's most dangerous flaw: Semantic Vulnerability (Indirect Prompt Injection). By dividing advanced mathematical R&D and application deployment, we push architectural boundaries in real-time environments.

The Evolution of Our Proof of Concept (POC)

Previously, our research operated as isolated components: a standalone live endpoint and the open-source Bangsaen Black Hole repository on GitHub. This Capstone Project unites both into a single, comprehensive, two-layer integrated POC. Running entirely on Google Cloud Run, it serves as a live defense endpoint to prove absolute lightweight execution and validation under heavy automated traffic.

🛡️ Core Innovation: Cloud-Native Two-Layer Filter

Hosted centrally on Google Cloud Run to guarantee sub-2ms processing speeds.

  • Layer 1 (Agentic Gateway): Acts as a strict domain boundary. It evaluates incoming queries against a specific subspace generated from our 2-book knowledge base, instantly dropping out-of-bounds traffic.
  • Layer 2 (Koopman Core & Black Hole): Projects incoming semantics into a high-dimensional linear space. Using the invariant equation $$Ax = b$$, malicious payloads or poisoning intents are forced into the Left Null Space and completely zeroed out in RAM.
🧠 Student Execution: Downstream LLM & RAG Systems

Students simulate the target infrastructure on local development environments.

  • Identical Knowledge Base Alignment: Students process and fine-tune/RAG their LLM instances using the exact same two-book dataset used by the gateway. This ensures a synchronized semantic perimeter.
  • Payload Consumability: The student's local LLM only receives data that has successfully cleared the Cloud Run defensive layers. They focus on optimized inference and context retrieval, free from semantic injection attacks.

Empirical Infrastructure Benchmarking

To bridge the gap between cloud infrastructure and local nodes, the Cloud Run gateway forwards sanitized payloads directly to the students' local machines via secure network tunnels.
